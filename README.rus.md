# Бот домашних заданий

Readme: [English](/README.md) | <u>Русский</u>

Telegram-бот для учебной группы. Администратор публикует задания, а студенты быстро находят сегодняшние, завтрашние, активные и прошедшие задания. Данные хранятся в SQLite; завершившиеся задания остаются в базе и доступны через историю.

## Возможности

**Команды для студентов**

- `/today` – задания со сроком сдачи сегодня
- `/tmrw` – задания со сроком сдачи завтра
- `/active` – выбор месяца с активными заданиями
- `/active all` – все активные задания
- `/history` – выбор месяца с прошедшими заданиями
- `/history 2026-04-11` – все прошедшие задания с этим сроком
- `/history 2026-04-11 Математика, Физика` – задания только по названным предметам

**Команды администратора**

- `/share` – опубликовать новое задание (по шагам: предмет → описание → опционально фото → дата начала → срок сдачи)
- `/edit` – изменить существующее задание (предмет, описание, фото, даты)
- `/delete` – удалить задание
- `/cancel` – отменить текущую многошаговую операцию

Пример запроса студента:

```
/history 2026-04-11 Математика, Физика

Математика
От: 01.04.2026
До: 11.04.2026

Решить задачи 1–15.
```

После `/share` бот последовательно попросит предмет, описание (текст или фото с подписью), опционально фото, дату начала и срок сдачи. Даты вводятся в формате `2026-11-03` или с временем `2026-11-07 23:59`. Если время срока не указано, используется 23:59.

## Технологии

- **Python**
- **pyTelegramBotAPI** (TeleBot)
- **SQLite** (одна таблица `homework`)
- **python-dotenv**
- **tzdata** / `zoneinfo` (поддержка часовых поясов, по умолчанию `Asia/Bishkek`)
- **pytest**

Структура проекта:

```
bot/
├── config.py
├── main.py
├── database/ # База данных и репозиторий
├── handlers/ # Обработчики команд студентов и администратора
├── services/ # Бизнес-логика
└── utils/ # Даты, форматирование, вспомогательные функции
```

## Установка и запуск

1. Клонируйте репозиторий:

   ```
   git clone https://github.com/aidartheklutz/homework-database-tgbot.git
   cd homework-database-tgbot
   ```

2. Создайте и активируйте виртуальное окружение:

   ```
   python -m venv .venv
   source .venv/bin/activate # Linux/macOS

   # или .venv\Scripts\activate на Windows

   ```

3. Установите зависимости:

   ```
   pip install -r requirements.txt
   ```

4. Скопируйте пример файла окружения и заполните значения:

   ```
   cp .env.example .env
   ```

   ```
   BOT*TOKEN=ваш*токен_бота
   ADMIN_IDS=123456789,987654321
   DATABASE_PATH=homework.db
   TIMEZONE=Asia/Bishkek
   ```

5. Запустите бота:
   ```
   python main.py
   ```

Файл `homework.db` создаётся автоматически рядом с точкой запуска. Схема содержит одну таблицу `homework`; статус задания (активное / прошедшее) вычисляется по полям `start_at` и `deadline` в настроенном часовом поясе.

## Развёртывание

На сервере задайте те же переменные окружения, обеспечьте постоянное хранилище для файла SQLite и держите процесс запущенным через systemd, Docker или другой менеджер процессов. Для MVP используется long polling, поэтому одновременно должен работать только один экземпляр бота с одной базой.

## Очистка тестовых данных

Для разработки доступна функция `clear_current_database` из `bot.utils.development`. Она удаляет все записи домашних заданий из базы, указанной в `.env`, и **не является** Telegram-командой:

```
python -c "from bot.utils.development import clear_current_database; print(clear_current_database())"
```
